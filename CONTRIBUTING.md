# Contributing

Issues and pull requests are welcome.

- Read [AGENTS.md](AGENTS.md) first. It covers the commands, the workflow, the contract
  between the app and the plugin, and the code style. It applies to people and agents.
- One branch and one pull request per change. Say in the PR which test suites you ran
  and their counts, since there is no CI.
- Test against wp-env, never against a real site.
